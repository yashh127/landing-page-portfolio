# Apex Studio — Freelance Landing Page Portfolio

A modern, high-converting portfolio website designed to sell complete landing page solutions (Copywriting + UI Design + Responsive Code).

---

## 🚀 How to View Locally on Your Mac

You don't need any complex build tools. Open your terminal or run directly:

### Option 1: Direct Browser Launch
```bash
open /Users/yash/.gemini/antigravity/scratch/landing-page-portfolio/index.html
```

### Option 2: Run a Local Dev Server (Python)
```bash
cd /Users/yash/.gemini/antigravity/scratch/landing-page-portfolio
python3 -m http.server 8080
```
Then visit `http://localhost:8080` in Safari or Chrome.

## 🌐 How to Host for Free (in 2 Minutes)

To send this link to prospective clients, you can host it 100% free with a custom or `.vercel.app` domain:

### Method 1: Vercel (Recommended)
1. Install Vercel CLI (or drag-and-drop the folder at [vercel.com](https://vercel.com)):
   ```bash
   npx vercel
   ```
2. Follow the 2-step prompt. It will give you an instant live URL (e.g. `apex-studio.vercel.app`).

### Method 2: GitHub Pages
1. Push this folder to a GitHub repository.
2. In Repository Settings &rarr; Pages &rarr; Set source to `main` branch.
3. Your site will be live at `yourusername.github.io/landing-page-portfolio`.

## 📁 File Structure
- `index.html`: Semantic, accessible structure with high-converting sections (Hero, Comparison, Showcase, Process, Pricing, FAQ, Contact).
- `styles.css`: Dark-mode aesthetics, fluid `clamp()` typography, CSS grid, and modern viewport mechanics.
- `script.js`: Interactive project filter tabs, pricing-to-contact form synchronization, and feedback handling.
- `PITCH_TEMPLATES.md`: Copy-paste proposal scripts for Upwork, Twitter/X DMs, and cold outreach.
